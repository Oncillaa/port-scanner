# 🔍 Port Scanner

Многопоточный TCP/UDP сканер портов с баннер-граббингом.

## Возможности

- Сканирование TCP и UDP портов
- Баннер-граббинг (определение сервисов)
- Определение ОС
- 200+ потоков
- 8 режимов сканирования
- Экспорт в TXT и JSON

## Технологии

- Python 3.11
- socket, threading, json

## Установка

git clone https://github.com/Oncillaa/port-scanner.git
cd port-scanner
python scanner_cli.py

## Использование

Запусти и выбери режим сканирования. Или:

python port_scanner.py

## ⚠️ Только для образовательных целей

## 🔧 Как это работает

1. Сканер создаёт потоки (до 200 одновременно)
2. Каждый поток подключается к порту
3. Если порт открыт — отправляет запрос для определения сервиса
4. Ответ сравнивается с базой сигнатур
5. Результат выводится на экран и сохраняется

## 📁 Структура проекта
1. port_scanner.py — основная логика
2. scanner_cli.py — интерфейс командной строки
3. banner_grabber.py — определение сервисов
4. signatures.json — база сигнатур
5. config.yaml — настройки

## ⚠️ Ограничения

- Не обходит файрволы
- UDP сканирование медленнее TCP
- Для портов ниже 1024 нужны права администратора
